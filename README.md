# InnerTune - Ads Free Music Streaming for Android 🎶

![Version](https://img.shields.io/badge/version-0.5.9-blue)
![License](https://img.shields.io/badge/license-MIT-green)
![Android](https://img.shields.io/badge/platform-Android-brightgreen)

**InnerTune** is a sleek and ads-free music streaming app for Android. It offers a minimalist design, fast performance, and an uninterrupted listening experience without the distraction of ads.

## Features ✨

- 🎵 **Ads-Free Music Streaming**: Enjoy music without any interruptions.
- 💾 **Offline Playback**: Save your favorite tracks for offline listening.
- 📑 **Playlist Creation**: Create and manage playlists for every mood.
- 🔍 **Powerful Search**: Find the music you love instantly.
- 🎛 **Customizable Interface**: Modify the app to suit your aesthetic.
- 🚀 **Lightweight & Fast**: Designed for optimal performance on Android devices.

## Installation 📲

1. Download the latest APK from the [Releases](https://github.com/likhown/InnerTune/releases) page.
2. On your Android device, go to **Settings** > **Security** > enable **Unknown Sources**.
3. Open the APK file to install the app.
4. Once installed, open InnerTune and start streaming your favorite music ad-free!
